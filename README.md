# Housing 智能匹配

## Windows 离线版

网页右上角“切换离线版”可下载 Windows 便携包。完整解压后运行 Housing-Offline.exe，无需安装 Python。程序通过本地文件窗口选择 STEP/STL，再由本机网页测量，不需要浏览器上传文件权限。无需联网即可使用随包数据库、解析器、进度条与红绿对比。原始文件仅在内存中处理，关闭启动器后清除。

离线版使用发布时的内置数据库快照，不连接或同步共享库，不提供共享资料增删改。公司若限制本地程序、文件读取或本机服务访问，需由 IT 审核授权。不能把切换离线视为绕过公司安全策略。详情见 offline/README.txt。

打包：Windows 上运行 `npm ci --ignore-scripts`、`npm run build`、`pip install pyinstaller==6.22.3`、`python scripts/build-offline.py`。CI 会构建便携包并放到网页的 offline 下载目录。所有资源随包携带；首次下载安装包需要联网或同事拷贝。

V2.0：内置 141 条真实 Excel Housing 数据，无需反复上传 Excel。测量在浏览器本机进行；连接后台后，授权用户可确认保存产品信息与原始 CAD 到共享库。未配置云端时仍可使用内置库匹配。

共享库支持公开查询与匹配、用户名密码登录、授权编辑、原始文件下载、回收站恢复、管理员账号授权和 ZIP 导出。云端服务尚需部署，详见 [后台部署与备份说明](backend/DEPLOY.md)。前端源码与后台部署文件均已包含，账号密码不存放在网页中。

## 使用

请通过 https://yhao68142-maker.github.io/housing-matching/ 打开网页。不要双击下载目录中的 index.html 来自动测量：file:// 模式会被浏览器阻止启动解析 Worker。本地文件版提供在线入口，并保留手动匹配功能。本机部署请先构建，再用 HTTP 服务访问 dist 目录。

1. 选择 STEP/STP 或 STL（不超过 30 MB），或直接手动输入长度、宽度。
2. STL 无单位信息，选择导出时使用的单位。STEP 输出统一为毫米。
3. 自动测量模型坐标轴包围盒，默认最长轴为长、次长轴为宽，可以手动调整轴映射。斜放模型必须在 CAD 中对齐后导出；旋转预览不会改变测量。
4. STEP 自动识别主底面与尾部底面。唯一候选会将台阶高、台阶长保留两位小数填入；多个候选需选择、核对高亮区域后采用。测量示意中绿色为垂直高差，红色为端部到过渡边长度。支持手动改值与反转高度符号。STL 暂不自动识别台阶，未知时留空。零值与未知不同，整体高度不能代替台阶高度。
5. 开始匹配，查看 TOP 10、各维差值、覆盖率和待核对提示；可导出 CSV。

SLDPRT 不在此静态版本的解析范围，请从 SolidWorks 另存为 STEP。没有浏览器端 SLDPRT 转换功能。STEP 使用 occt-import-js 0.0.23 的 OpenCascade WebAssembly，网格化参数为 0.01 mm 弦偏差，包围盒为网格近似值，不是工程公差认证结果。当前没有自动孔、槽或整体形状识别。

### 台阶识别范围（V1.1）

由 STEP 曲面分组的三角面提取与坐标轴垂直的平面，寻找同一实体、同一外法向、宽度重叠的主底面和端部底面。排除上下表面厚度、独立实体之间的距离和小面积孔槽。高度取两个底面的垂直高差，并按主底面外法向决定符号；如原数据库方向定义相反，可反转符号。

长度取模型端部至过渡边的长度轴投影，不使用尾部底面自身长度。存在贴近主底面高度、横跨宽度的窄肩面时，采用该肩面靠尾部的横边；否则使用主底面靠尾部的边。该启发式针对端部底面台阶，复杂、多级、分体或未对齐模型可能无法唯一识别，须核对高亮和原图。算法完全根据几何测量，不查询数据库猜测台阶尺寸。坐标轴变化会清除旧台阶并重新识别，未找到时不填零。

已用用户提供的 300-1047 STEP 在本机验证：高 3.4001685 mm、长 35.2942641 mm，主底面面积 1662.329 mm²，肩部横边宽 21.98 mm，与参考截图一致。原始 CAD 文件未发布到仓库。输入框为 3.40 / 35.29 mm，四个尺寸一起匹配。提供本地环境变量 HOUSING_TEST_STEP 可复测真实样本；公共 CI 使用合成几何测试，并跳过未提供的私有样本。

## 数据与评分

来源：Housing和连板&COC-尺寸统计.xlsx，Housing 第 3–143 行；源文件 SHA256 记录在 housing-data.js。填充仅发生在原有合并单元格范围，行号用作唯一标识，原序号的重复不造成覆盖。

保留原文和负值，未知尺寸为 null。11 条记录存在缺失台阶或异常数值提示，未擅自交换疑似填反的字段。Panel/COC 不属于本次 Housing 匹配库。原 Excel 中图片未内嵌，可按原行号回查图纸。

权重：长度 40、宽度 30、台阶高 20、台阶长 10。仅使用用户已填维度，误差 = min(abs(输入 − 库值) / 容差, 1)，库值缺失时误差为 1。得分 = 100 × (1 − 加权平均误差)。覆盖率为有库值维度的权重占比；分数不是概率。严格模式要求全部已填维度有库值且在容差内。同分按覆盖率、原表行排序，并不宣称唯一识别。

## 开发与发布

Node.js 22：`npm ci --ignore-scripts`、`npm test`、`npm run build`。将 dist 作为静态目录通过 HTTP 服务访问。运行时不依赖第三方 CDN，CAD 引擎随网站发布。

GitHub Pages 的 Source 选择 GitHub Actions。推送 main 后工作流测试、构建并发布 dist。首次需在 Settings → Pages 启用 GitHub Actions。网页与内置数据库是公开可访问的静态内容。

更新数据库：安装 Python openpyxl 后执行 `python scripts/convert.py path/to/source.xlsx .`，核对原文和异常标记，再提交 housing-data.js。当前转换器要求此版表格的 141 行，表格结构变化时需要同步调整校验。

第三方解析器：[occt-import-js](https://github.com/kovacsv/occt-import-js)，LGPL-2.1；其许可证随构建复制至 vendor/LICENSE.md。解析器保留为可替换的独立 JS/WASM 文件，未修改其源码。
